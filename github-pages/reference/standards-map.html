The folders below name the operator's optional local specification library. docs/ is gitignored and ships with nothing, so it starts empty: python scripts/fetch_tel_docs.py downloads every freely published source in its manifest (--list prints the manifest, --manual the documents that need a click-through or a purchase, with the file name each must be saved under), and python scripts/convert_tel_docs.py packs each one into docs/tel-docs/converted/<folder>/: the full text, a pages/ copy to grep, a tables/ directory, and verbatim asn1/ extracts. _index.md is the catalogue. Versions coexist on purpose -- encode against the version the peer declares, not the newest text -- so a folder name carries its version and this table names the newest packed one.

The exception is the RSPRO ASN.1 schema, redistributed as Tools/HilBridge/RSPRO.asn package data so the HIL bridge works from a plain pip install.
